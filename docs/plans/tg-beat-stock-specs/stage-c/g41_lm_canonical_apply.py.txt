"""G41 (round 6): --lm-prefill-canonical, an opt-in mode in which a cache hit equals a fresh run bit for bit (stock decode and --hybrid-moe-frozen).

Why: rounds 3-5 reported the suite's hit-versus-fresh checks as failing and called a bit-equal hit "not delivered by a server with a prefix cache". That was an expectation, never tested. A hit differs from a fresh run
in how the prompt is partitioned into batches: the cached prefix was computed inside an earlier request (its batches ended 516 and 4 tokens before the prompt's end, for the checkpoints), the tokens that decode produced
were computed one at a time, and the resumed pass starts wherever the checkpoint was. The layer-major pass already cuts its chunks at absolute multiples of the chunk size (G35). What was missing is a prompt whose OTHER
seams also sit on those boundaries:
 - checkpoints only at multiples of the chunk size (the batch that ends the prompt is cut at the last multiple below N, N-1 at most; no 4 + ubatch tail, no 4-token tail, no user-message checkpoints), created by the
   batch that starts there;
 - a continuation always resumes from the newest such checkpoint that precedes the common prefix of the old and the new prompt (never from the state that decode left behind), or from 0 when there is none, and
   everything after it is prefilled again;
 so that the tokens after a checkpoint are prefilled in the same chunks as in a fresh run: the pass cuts [A, N) at the same absolute boundaries, the part that is shorter than --lm-prefill-min takes the same ordinary path with the
 same batch width, and the KV below A comes from complete aligned chunks of the earlier request.
Price: a repeat or a short follow-up re-prefills up to one chunk (2,048 tokens, ~1 s) beyond its new tokens instead of 4. Needs --lm-prefill, context checkpoints (default) and -b a multiple of --lm-prefill-ubatch.
Edits: common/common.h, common/arg.cpp, tools/server/server-context.cpp."""

def patch(path, edits):
    d = open(path, "rb").read().decode("utf-8")
    crlf = "\r\n" in d
    text = d.replace("\r\n", "\n")
    for old, new in edits:
        if text.count(old) != 1:
            sys.exit("anchor matched %d times in %s: %r" % (text.count(old), path, old[:80]))
        text = text.replace(old, new)
    if os.environ.get("PATCH_DRY"):
        print("DRY-OK", path)
        return
    if os.environ.get("G22_APPLY") != "1":
        sys.exit("refusing to edit the nested tree: set G22_APPLY=1 (PATCH_DRY=1 first)")
    if crlf:
        text = text.replace("\n", "\r\n")
    open(path, "wb").write(text.encode("utf-8"))
    print("patched", path)
