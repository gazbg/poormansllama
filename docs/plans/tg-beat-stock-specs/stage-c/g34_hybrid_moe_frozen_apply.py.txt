"""G34 (round 3 of the review of the layer-major integration): `--hybrid-moe-frozen`, the deterministic mode of the hybrid decode as a first-class flag.

The dynamic hybrid decode is not residency-invariant: which experts run on the GPU and which on the host follows the cache state, which changes with every request (promotions) and with the
history. The two legs agree to ~1.5% of the output (ggml-cpu q8_K activations against the GPU's q8_1; the G33 experiment brought that to 3e-5 with a q8_1-style host kernel, 500-2000x closer) but
not bit for bit, and the activation quantization of the next matmul re-rounds any ulp difference into a ~0.016-nat first-token difference: identical requests differ above the 0.25-nat rule in
4-10% of the pairs (results file, Round 3). With the cache frozen (a fixed slot count and no promotions) the residency never changes, the decode is deterministic and every hit-versus-fresh
expectation of the multi-turn suites is met. The isolating configuration used so far was --hybrid-moe-slots N plus the environment variable LLAMA_MOE_HYBRID_B=0; this makes it one flag.

  --hybrid-moe-frozen   fixed expert cache of --hybrid-moe-slots slots (default 16) and no promotions: identical requests give identical output; slower decode than the dynamic cache

Edits: common/common.h, common/arg.cpp, tools/server/server-context.cpp."""

def patch(path, edits):
    d = open(path, "rb").read().decode("utf-8")
    crlf = "\r\n" in d
    text = d.replace("\r\n", "\n")
    for old, new in edits:
        if text.count(old) != 1:
            sys.exit("anchor matched %d times in %s: %r" % (text.count(old), path, old[:80]))
        text = text.replace(old, new)
    if os.environ.get("PATCH_DRY"):
        print("DRY-OK", path)
        return
    if os.environ.get("G22_APPLY") != "1":
        sys.exit("refusing to edit the nested tree: set G22_APPLY=1 (PATCH_DRY=1 first)")
    if crlf:
        text = text.replace("\n", "\r\n")
    open(path, "wb").write(text.encode("utf-8"))
    print("patched", path)
