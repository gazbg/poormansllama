"""G28 (segmented layer-major prefill; contract in the plan): opt-in `--pp-segment-tokens S`. The layer-major prefill keeps the inter-layer activations of the WHOLE prompt in a GPU slab
(16 KiB per prompt token in f32), which breaks the owner's "16,000 MiB stay free during the whole run" rule at long prompts. With S the chunk list is processed in segments of S tokens:
for each segment the memory contexts of its chunks are applied, the chunks are embedded, the sweep over all layers runs, and the output graphs run, against a slab that holds ONE segment.
Per layer the chunks are still visited in ascending order, so the arithmetic is the unsegmented one; each segment streams the layer banks once more. Default (flag absent) = one segment =
the historical order (the apply loop is moved into a lambda and called once at the same place; the stage loops run once over all chunks).

new tests/test-layer-streaming-segments.cpp (stage-c/g28_test_segments.cpp.txt, host-only) + its registration in tests/CMakeLists.txt.
