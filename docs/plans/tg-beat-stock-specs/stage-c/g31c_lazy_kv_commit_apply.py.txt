"""G31 / S2: lazily committed KV with on-demand commit, and the hybrid cache giving way to it. Contract: docs/plans/llama-server-integration.md.

Measured (g211/g213, build s1): with --hybrid-moe and the full 262,000-token KV committed (2.7 GB) the expert cache gets 17 slots per layer under the 16,000 MiB keep-free target; the KV rows of a
context that is mostly empty are VRAM the cache could use. The CUDA backend already has a lazily committed KV buffer (LLAMA_KV_LAZY, used by the runner, which commits the rows of its one prompt up front;
reads of uncommitted pages return zeros through a shared read-only granule, a write to one faults). The server writes cells at positions it does not know in advance, so the commit must follow the writes:

 * ggml-cuda.cu: ggml_backend_cuda_lazy_commit_cost(rows) = the physical bytes committing the first `rows` rows would still map.
 * llama-kv-cache.h/.cpp: with LLAMA_KV_LAZY (single stream, flash-attention layout) the cache commits rows [0, max written cell + 1 + headroom) in steps of 4096 rows BEFORE a ubatch is applied
   (llama_kv_cache_context::apply, and the state restore path); a failed commit makes the decode fail loudly (no silent write to an uncommitted page); everything that touches the whole window
   (K shift) commits all rows first. Before a commit it calls a pressure callback with the bytes it is about to map, so the VRAM expert cache can make room.
 * llama-moe-hybrid.cpp / llama-hybrid-api.cpp / llama-hybrid.h: llama_hybrid_set_margin(keep_free, safety, slack): registers that callback; it synchronizes the device and shrinks the expert cache so that
   `keep_free + safety` MiB stay free after the commit (plus a slack so that the next commits do not shrink again), and drops the context's cached decode graph. prepare_env turns LLAMA_KV_LAZY on.
Without the environment variable nothing changes. Apply after g31b. G22_APPLY=1 (PATCH_DRY=1 first; G22_NEST=<copy root>)."""

patch(HY, [
    (r'''// G31: size the cache to a keep-free target (the rule of the runner's tg_transition(), plus shrinking).''', r'''bool llama_moe_hybrid_make_room_impl(int64_t need_free_bytes, int64_t slack_bytes, int min_slots, bool * shrunk) {
    if (shrunk != nullptr) {
        *shrunk = false;
    }
    moe_hybrid_engine * eng = nullptr;
    {
        std::lock_guard<std::mutex> lk(g_moe_hybrid_mtx);
        if (g_moe_hybrid_engines.size() != 1) {
            return false;
        }
        eng = g_moe_hybrid_engines.begin()->second.get();
    }
    if (eng->cache_buf == nullptr || eng->cuda == nullptr) {
        return false;
    }
    ggml_backend_dev_t dev = ggml_backend_get_device(eng->cuda);
    size_t free_b = 0, total_b = 0;
    ggml_backend_dev_memory(dev, &free_b, &total_b);
    if ((int64_t) free_b >= need_free_bytes) {
        return true;
    }
    const int64_t cache_bytes = (int64_t) ggml_backend_buffer_get_size(eng->cache_buf);
    const int64_t row_bytes   = cache_bytes / (eng->n_slot + 1);
    if (row_bytes <= 0) {
        return false;
    }
    const int64_t deficit   = need_free_bytes - (int64_t) free_b + slack_bytes;
    const int64_t drop_rows = (deficit + row_bytes - 1) / row_bytes;
    const int     new_slots = (int) std::max<int64_t>(std::max(1, min_slots), (int64_t) eng->n_slot - drop_rows);
    if (new_slots >= eng->n_slot) {
        return true;   // already at the floor: the caller tries the commit anyway
    }
    ggml_backend_synchronize(eng->cuda);   // a graph of the ubatch before this one may still read the cache
    LLAMA_LOG_INFO("%s: moe_hybrid: device memory is short by %.1f MiB: expert cache %d -> %d slots per layer\n", __func__, (double) (need_free_bytes - (int64_t) free_b)/1048576.0, eng->n_slot, new_slots);
    if (!llama_moe_hybrid_resize_impl(new_slots)) {
        return false;
    }
    if (shrunk != nullptr) {
        *shrunk = true;
    }
    return true;
}

// G31: size the cache to a keep-free target (the rule of the runner's tg_transition(), plus shrinking).'''),
