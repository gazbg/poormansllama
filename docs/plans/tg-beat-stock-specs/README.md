# Session specs of the TG-beat-stock goal (G5-G7 and the final-build G3/G4 sessions)

Inputs for `python tools/run-tg-arms.py --spec <file>`; run each inside one GPU-mutex hold with the build under test named LAST on the wrapped command line, e.g.

    powershell -NoProfile -File tools/with-gpu-lock.ps1 -VerdictTag g12-g5 -Command "python tools\run-tg-arms.py --spec docs\plans\tg-beat-stock-specs\g12-g5.json --attest build\llama-cuda\bin\g12\llama-layer-streaming.exe"

The specs name `build/llama-cuda/bin/<tag>` side-copies (rebuild and side-copy first) and the model / prompt paths of the dev machine. `g11-queue.sh` is the order the final-build sessions ran in.
Meaning of each spec: see `docs/plans/tg-beat-stock-8gb-262k.md` (G4-G7 contracts and results). Note: `run-tg-arms.py` writes the verdict next to the session directory under `build/llama-cuda/`, which is not versioned.

Generators of the later sessions (run `python <generator>.py`; each writes `build/llama-cuda/specs/<session>.json` and a copy here): `mk_qa.py` (needle QA of the final recipe), `mk_deep.py` (deep-fill QA / speed arms), `mk_final.py` (keep-free comparison with stock), `mk_g43.py` .. `mk_g45.py` (GQA8 and prefill-recipe sessions), `mk_g46.py` (short-prompt sweep, stock against layer-major), `mk_g47.py` (the final configuration on a dedicated GPU: QA at six lengths and the headline against stock), `mk_g48.py` (diagnostics: plain batch-major at 200k / 250k, f16 KV, MTP re-measure), `mk_g49.py` (stock prefill with the op offload off and with ubatch 2048), `mk_g52.py` / `mk_g53.py` (slot-window sweeps of the layer-major prefill, cold and warm), `mk_g50.py` (the CPU leg of the layer-major prefill, `--pp-cpu-layers`, g43), and the G23 set of build g43 / g44 (contract and results in the plan): `mk_g54.py` (smoke `g55-*`, stock path `g56-stock-*`, paced copies `g57-pace-*`), `mk_g59.py` (needle QA smoke through the new paths), `mk_g64.py` / `mk_g65.py` / `mk_g66.py` / `mk_g78.py` (root-cause sessions of the slow CPU-only path), `mk_g68.py` (the final comparison, the headline table), `mk_g69.py` (default-off identity), `mk_g70.py` / `mk_g76.py` (paced copies on 4,096 to 200,000 tokens), `mk_g73.py` (decode regression guard); the edit scripts that built g41..g44 are `stage-c/*.txt` (apply in order: apply_g22_cpuleg, g23_pacing_apply, g23_stockpath_apply, g23_fix1 .. g23_fix4; copy to a scratch `.py`, `G22_APPLY=1`, `PATCH_DRY=1` first). Tables: `python tools/g23-table.py hybrid|stock|pace|final|ident|deep`. Queues: `run-session-queue.sh <build> <session> ...`.
